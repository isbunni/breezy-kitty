# 🐱 breezy-kitty

Kitty terminal emulator configuration — part of the [breezy-dotfiles](https://github.com/isbunni/breezy-dotfiles) ecosystem.

## Usage

```bash
git clone https://github.com/isbunni/breezy-kitty.git
ln -sf ~/breezy-kitty/kitty.conf ~/.config/kitty/kitty.conf
```

## Install via breezy-dotfiles

The parent repo includes this as a git submodule — it gets symlinked automatically.

```bash
git clone --recurse-submodules https://github.com/isbunni/breezy-dotfiles.git
cd breezy-dotfiles
./install.sh
```
